# BookingManagmentSystem

REST API для керування залами та їх бронювання. Дозволяє знайти вільний зал за датою, часом і місткістю, обрати доступні послуги та отримати підтвердження із загальною вартістю.

## Можливості

- Перегляд, створення, редагування й видалення залів; налаштування доступних для них послуг.
- Пошук вільних залів і бронювання з перевіркою перетинів.
- Розрахунок погодинної оренди за часовими тарифами. Послуги оплачуються разово.

Бронювання доступне з 06:00 до 23:00 в межах одного дня. Система зберігає ціни на момент бронювання та захищає від подвійного бронювання під час одночасних запитів.

## Стек

C#, ASP.NET Core / .NET 8, Entity Framework Core 9, SQL Server, Swagger, Serilog. Для контейнерного запуску є Dockerfile та Docker Compose.

## Локальний запуск

Проект можна запустити локально змінивши тільки рядок підключення до БД на вашу в файлі конфігурації `BookingManagmentSystem.API/appsettings.Development.json`

Або ж можна запустити за допомогою Докера

1. SQL Server можна підняти через `docker compose up -d sqlserver`.

2. Також за допомогою команди `docker compose up -d --build api` можна підняти саму апі та звертатися за адресом наведеним нижче.

Swagger: [localhost:8080/swagger](https://localhost:8080/swagger).

Автоматичне застосування міграцій і заповнення початковими даними вимкнене. Ввімкнути можна розкоментувавши методи в `BookingManagmentSystem.API\Program.cs`

## Основні запити

| Метод | Маршрут | Призначення |
|---|---|---|
| GET, POST | `/api/halls` | Список залів / створення залу |
| PUT, DELETE | `/api/halls/{id}` | Оновлення / видалення залу |
| GET | `/api/services` | Список послуг |
| GET | `/api/halls/available` | Пошук за `startTime`, `endTime`, `capacity` |
| POST | `/api/bookings` | Бронювання залу |

Приклади даних і бізнес-правила наведені в документації[PROJECT_DOCUMENTATION.md](https://github.com/mxtam/BookingManagmentSystem/blob/develop/PROJECT_DOCUMENTATION.md).
